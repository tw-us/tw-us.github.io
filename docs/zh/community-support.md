# 把你的支援能力帶進社群

先讓你與家人的聯絡計畫可運作，再把可用的時間、專業與資訊擴大給社群。不要透過本站自行募集款項、收集受災資訊或派遣救援；危機時應加入已有責任、流程與現場網絡的組織。

## 先完成你的基礎準備

- [建立家人支援計畫](family-plan.md)
- 和家人演練一次報平安與備援聯絡流程
- 確認你只會轉傳能回到原始來源的資訊

## 分享已驗證的資訊

把官方準備指引與可信組織的行動頁傳給親友、同學、同事與社群。分享前確認日期、來源與適用地點；不轉傳未證實的軍事消息、匿名截圖或要求匯款的訊息。

## 用你的技能協助既有網絡

可提供的支援包括翻譯、資訊整理、數位安全、網站維護、活動協調、急救與社群聯絡。先詢問組織真正需要什麼，再承諾時間或資源。

## 參與公共倡議與教育

FAPA 的公開使命是向美國政策制定者、媒體、學者與公眾提供台灣議題資訊，並協助草根倡議。它在本站的角色是**公共倡議與教育**，不是緊急救援提供者。
