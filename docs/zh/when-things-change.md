# 看到消息時怎麼確認

<p class="lede">這個網站不預測戰爭，也不提供自訂的危機分數或警報判斷。先看家人所在地和台灣官方公告，再決定現在要做什麼。</p>

## 平常

沒有官方緊急指示時，把家人聯絡卡、備援聯絡方式、重要文件和能提供的協助準備好，並定期確認官方工具還能使用。

## 消息有變化時

看到可能影響家人的重大消息時，再確認一次聯絡方式，補足必要物資，下載離線資料，並對照官方公告和原始來源。新聞大量報導、單一社群貼文或網站上的分數，都不等於官方警報。

## 官方發布緊急指示時

<div class="action-callout">只有在<strong>官方發布明確緊急指示</strong>或<strong>家人所在地已受到直接影響</strong>時，才需要立即應變：先確認人身安全，照所在地官方指示行動，以約定方式報平安，再看看還需要哪些協助。</div>

## 其他資訊網站

[World Monitor](https://www.worldmonitor.app/) 可用來了解外部情勢，但它不是台灣或美國政府的官方警報來源。不要只看這個網站就決定是否採取行動。
