    支援更多急難的人¶

    在確保家人朋友安全後，你可以將支援範圍擴大到更多需要幫助的人。這是台美人團結力量的展現。

    參與台美組織緊急應變（第1-2小時）¶

    聯絡你所屬的台美組織¶

    按優先順序聯絡： - [ ] FAPA 分會：政治倡議與媒體發聲 - [ ] TAA 同鄉會：社區互助與資源協調
    - [ ] 專業組織：NATMA、NATPA 等專業支援 - [ ] 教會組織：台灣基督教會、佛教慈濟等

    組織緊急會議¶

    • 發起緊急電話會議：召集當地台美人領袖
    • 成立緊急應變小組：分工負責不同支援項目
    • 建立資訊中心：統一收集與發布消息
    • 協調避免重複：確保資源有效運用

    政治倡議行動（第2-6小時）¶

    聯絡政治代表¶

    立即聯絡你的國會議員： - [ ] 參議員辦公室：要求關注台海情況 - [ ] 眾議院代表：促請政府提供人道協助 - [ ] 州長辦公室：請求州政府支援台美人社區 - [ ] 市長辦公室：協調地方資源支援

    媒體發聲策略¶

    • 聯絡當地媒體：提供台美人觀點與需求
    • 社交媒體協調：統一發聲避免混亂資訊
    • 準備新聞稿：與FAPA協調統一對外聲明
    • 安排記者會：如情況重大需要公開呼籲

    政策推動重點¶

    • 人道主義支援：要求美國提供緊急人道協助
    • 撤離協助：如需要，要求協助美國公民撤離
    • 經濟支援：推動對台經濟援助方案
    • 軍事支援：支持對台軍事援助（依情況而定）

    資訊戰與闢謠（持續進行）¶

    建立可信資訊網絡¶

    • 官方消息來源：台灣政府、美國政府官方聲明
    • 可信媒體：BBC、CNN、台灣主要新聞台
    • 台美組織：FAPA、TAA 等組織發布的消息
    • 避免不可靠來源：社群媒體未經證實的消息

    反制假訊息¶

    常見假訊息類型與應對： - [ ] 誇大災情：以官方數據反駁 - [ ] 政治操作：提供客觀政治分析 - [ ] 散布恐慌：分享正確的應變資訊 - [ ] 分化社群：強調團結與互助

    正確資訊傳播¶

    • 事實查核：分享前先確認資訊來源
    • 多語言支援：提供中英文資訊服務
    • 長輩關懷：特別注意長輩容易被誤導
    • 青年動員：善用年輕人的社群影響力

    物資與資金募集（第6-24小時）¶

    緊急募款活動¶

    設立合法募款管道： - [ ] 通過 501©(3) 組織：確保捐款可抵稅 - [ ] 銀行專戶：設立緊急救助專戶 - [ ] 網路募款平台：GoFundMe、JustGiving 等 - [ ] 教會社群募款：透過宗教組織網絡

    募款目標優先級： 1. 緊急醫療與救援資金 2. 食物與民生物資 3. 通訊設備與電力設備 4. 長期重建資金

    物資收集與運送¶

    收集重點物資： - [ ] 醫療用品：急救包、藥品、醫療器材 - [ ] 通訊設備：充電寶、收音機、電池 - [ ] 食物：不易腐壞的食品、嬰兒食品 - [ ] 清潔用品：消毒液、肥皂、衛生紙

    運送安排： - [ ] 聯絡運輸公司：DHL、FedEx、UPS 國際運送 - [ ] 協調海運：大量物資海運較經濟 - [ ] 政府管道：透過外交管道運送 - [ ] 民間組織：紅十字會、慈濟等管道

    社區互助支援（持續進行）¶

    建立互助網絡¶

    支援在美台灣人： - [ ] 心理支援：為焦慮的台美人提供諮商 - [ ] 資訊支援：建立資訊分享群組 - [ ] 經濟支援：協助有經濟困難的台美人 - [ ] 法律支援：協助處理相關法律問題

    協助新來美國的台灣人¶

    如有台灣人緊急來美： - [ ] 機場接機：組織志工接機服務 - [ ] 暫時住宿：提供短期住宿協助 - [ ] 生活指導：協助適應美國生活 - [ ] 工作協助：協助尋找工作機會

    長期社區建設¶

    • 建立常設應急機制：為未來緊急情況做準備
    • 加強組織連結：強化各台美組織間合作
    • 培養領導人才：培養下一代台美領袖
    • 擴大政治影響力：增加台美人政治參與

    專業技能貢獻（依個人專長）¶

    醫療專業人員¶

    • 提供遠距醫療諮詢：協助評估傷患情況
    • 協調醫療物資：運用專業網絡取得醫療用品
    • 培訓急救技能：教導社區基本急救
    • 聯絡醫療機構：協調美國醫院支援

    IT與通訊專業¶

    • 建立通訊網絡：架設緊急通訊系統
    • 網站與資訊系統：建立資訊共享平台
    • 資安支援：保護重要資訊系統
    • 技術支援：協助解決技術問題

    法律專業人員¶

    • 移民法律諮詢：協助處理簽證與移民問題
    • 非營利組織法律：協助成立或運作救助組織
    • 國際法諮詢：提供國際法律觀點
    • 合約與法律文件：協助處理各種法律文件

    媒體與傳播專業¶

    • 新聞報導：提供專業新聞觀點
    • 社群媒體管理：協調線上資訊傳播
    • 翻譯服務：提供中英文翻譯
    • 公關策略：協助制定公關與傳播策略

    國際連結與合作¶

    與其他台僑社群合作¶

    • 歐洲台灣社群：協調跨洲支援行動
    • 澳洲紐西蘭台僑：資源共享與資訊交換
    • 日本台僑：地理位置相近的特殊合作
    • 加拿大台僑：北美台僑聯合行動

    與國際組織合作¶

    • 聯合國相關組織：WHO、UNICEF 等
    • 國際紅十字會：人道救援合作
    • 國際非政府組織：Oxfam、MSF 等
    • 宗教組織：各宗教的國際救援網絡

    行動效果評估¶

    短期效果指標（24-72小時）¶

    • 成功聯絡並協助多少人
    • 募集資金與物資數量
    • 媒體報導與政治關注度
    • 社區動員參與人數

    中期效果指標（1-4週）¶

    • 建立的長期支援機制
    • 政策推動的具體成果
    • 國際關注與支援程度
    • 台美社區組織的強化程度

    核心策略¶

    1. 先近後遠：先確保家人，再協助他人
    2. 專業分工：運用各人專長，避免資源重疊
    3. 持續追蹤：不只是一次性支援，要建立長期機制
    4. 團結合作：與所有台美組織協調行動
    5. 國際視野：連結全球台僑力量

    記住：每個人的專長都有用武之地。不論你的背景如何，都能為更多急難中的人貢獻力量。集結眾人之力，就能創造改變的力量。
