# 為社會與其他人準備

身在美國的台灣人，你的每一個行動都能為台灣的安全與未來貢獻力量。

## :loud_megaphone: 政治倡議與遊說

### 台灣人公共事務會 (FAPA)
**🌐 [fapa.org](https://fapa.org)**

FAPA 是美國最重要的友台政策遊說組織，自1982年成立以來持續在國會山推動友台政策。

**立即行動**：
- [ ] 找到你所在州的 [FAPA 分會](https://fapa.org/chapters/)並加入
- [ ] 訂閱 FAPA 電子報，掌握最新政策動向
- [ ] 參與年度 FAPA 國會山參訪活動
- [ ] 捐款支持 FAPA 政策遊說工作

**FAPA 全美分會覆蓋**：AL, AZ, CA, CO, CT, DC, DE, FL, GA, HI, IL, IN, KS, KY, LA, MA, MD, MI, MN, MO, NC, NJ, NY, OH, OK, OR, PA, TN, TX, UT, VA, WA, WI

## :family: 社區組織與互助

### 全美台灣同鄉會 (TAA)
**🌐 [taa-usa.org](https://www.taa-usa.org)**

TAA 是最悠久的台美組織（1967年成立），專注於地方社群建設與民主自由價值推廣。

**立即行動**：
- [ ] 查找你附近的 [TAA 分會](https://www.taa-usa.org/taa-chapters)
- [ ] 參加地方同鄉會聚會，建立社區人脈
- [ ] 協助新移民與留學生適應美國生活
- [ ] 參與文化活動與教育推廣

**TAA 分會地區**：AZ, CO, DC, GA, IL, MA, MO, NY, OH, PA, TX, UT, WA

## :mortar_board: 專業組織參與

### 北美台灣醫師協會 (NATMA)
專業醫療人員的交流平台，提供醫療支援與專業發展。

### 北美台灣教授協會 (NATPA)  
學術界人士的重要網絡，推動台美學術交流。

### 台美公民聯盟 (TACL)
專注於公民權益與政治參與的組織。

## :memo: 立即可做的10件事

**政治參與**：
- [ ] 註冊投票，每次選舉都投票
- [ ] 聯繫你的國會議員，表達對台灣議題的關注
- [ ] 簽署支持台灣的請願書和倡議

**社區建設**：
- [ ] 加入至少一個台美組織
- [ ] 參加台灣文化活動與慶典
- [ ] 教導下一代台灣歷史與文化

**經濟支持**：
- [ ] 定期捐款給友台組織
- [ ] 購買台灣產品，支持台灣經濟

**資訊戰對抗**：
- [ ] 在社交媒體分享正確的台灣資訊
- [ ] 糾正對台灣的錯誤認知與偏見
- [ ] 學習識別中國大外宣與假訊息
