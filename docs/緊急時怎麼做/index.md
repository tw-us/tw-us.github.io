# 緊急時怎麼做

當緊急狀況發生時，每一分鐘都至關重要。保持冷靜，按照計畫行動。

## :rotating_light: 緊急狀況定義

**本指南適用於以下緊急情況**：
- 台海軍事衝突
- 大規模自然災害（地震、颱風、海嘯、土石流）
- 重大社會動亂
- 其他威脅民眾安全的緊急事件

[→ 詳細災害應對指南](災害應對指南.md) - 整合台灣官方應變原則

## :one: 第一時間（前30分鐘）

### 立即確認安全
- [ ] **聯絡台灣家人**：透過所有可用管道確認安全狀況
- [ ] **檢查官方消息**：關注台灣與美國政府官方發布
- [ ] **啟動通訊網絡**：通知家族群組與台美社區網絡
- [ ] **確保自身安全**：如果你在美國，確保周遭環境安全

### 資訊收集檢查清單
- [ ] 台灣中央氣象署、內政部消防署官方消息
- [ ] 美國國務院、國防部相關聲明  
- [ ] 駐美台北經濟文化代表處最新公告
- [ ] 可信賴新聞媒體的即時報導

## :two: 短期應對（前24小時）

### 協助急難的家人與朋友
**專注於直系親屬與最親近的朋友**

你需要：
- 確認他們的即時安全狀況
- 提供緊急資金支援
- 協助聯絡救援資源
- 維持定期聯絡

[→ 詳細指南：協助急難的家人與朋友](協助急難的家人與朋友/index.md)

### 支援更多急難的人
**擴大協助範圍到社區與其他需要幫助的人**

你需要：
- 參與台美組織的緊急應變
- 協助資訊傳播與闢謠
- 組織物資與資金募集
- 提供政治倡議支持

[→ 詳細指南：支援更多急難的人](支援更多急難的人/index.md)

## :three: 中期應對（前72小時）

### 持續監控與支援
- [ ] **建立定期聯絡機制**：每6-12小時確認家人狀況
- [ ] **協調物資支援**：根據需要提供食物、藥品、現金
- [ ] **聯絡救援組織**：如紅十字會、慈濟等救援團體
- [ ] **準備長期支援計畫**：評估可能需要的長期協助

### 政治與外交行動
- [ ] **聯絡國會議員**：促請美國政府提供協助
- [ ] **參與台美組織行動**：配合 FAPA、TAA 等組織的緊急倡議
- [ ] **社交媒體發聲**：傳播正確資訊，反駁假消息
- [ ] **組織社區支援**：動員當地台美人社區力量

## :warning: 緊急情況下的注意事項

### 通訊安全
- **多管道通訊**：不要只依賴單一通訊方式
- **資訊驗證**：只相信官方來源與可信媒體
- **避免恐慌傳播**：確認資訊正確性再轉發

### 資金安全
- **緊急匯款**：準備多種匯款管道（銀行、Western Union等）
- **現金準備**：確保有足夠現金應急
- **避免詐騙**：謹防假借緊急情況的詐騙行為

### 心理健康
- **保持冷靜**：恐慌無助於解決問題
- **尋求支援**：不要獨自承擔所有壓力
- **適當休息**：維持基本的睡眠與飲食

## :chart_with_upwards_trend: 情況評估指標

### 輕微緊急（黃色警戒）
- 局部性災害或事件
- 通訊基本正常
- 政府機能運作

**行動**：監控情況，準備支援

### 中度緊急（橙色警戒）  
- 區域性大規模災害
- 部分通訊中斷
- 政府動員應變機制

**行動**：積極聯絡，準備物資支援

### 嚴重緊急（紅色警戒）
- 全島性重大危機
- 大規模通訊中斷
- 國際關注與介入

**行動**：全面動員，最大程度支援

---

## :muscle: 核心原則

1. **家人優先**：先確保最親近的人安全
2. **有序行動**：按照計畫執行，避免混亂
3. **資訊準確**：只依據可信來源做決定  
4. **持續支援**：準備長期而非短期的協助
5. **團結合作**：與台美社區共同行動

記住：你在美國，你擁有獨特的資源與能力來幫助台灣。每個人的行動都很重要。
