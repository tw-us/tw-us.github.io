## :family_man_woman_girl_boy: 為家人與朋友準備

**核心任務：確保台灣親友的安全**

你可以從美國遠端協助台灣的家人朋友做好各種準備：

- **通訊準備**：建立多重通訊管道，包括斷網時的應急方案
- **物資準備**：協助採購或提醒準備緊急避難包
- **避難計畫**：協助制定撤離路線與避難策略
- **財務準備**：確保緊急情況下的資金支援

## :warning: 緊急徵兆識別

### 政治軍事徵兆
- [ ] 中國軍機繞台頻率異常增加
- [ ] 美國第七艦隊調動頻繁
- [ ] 台海軍事演習規模擴大
- [ ] 國際媒體大幅報導台海緊張

### 經濟金融徵兆  
- [ ] 台股、港股異常劇烈波動
- [ ] 中國減持美國國債規模增加
- [ ] 兩岸貿易量異常變化
- [ ] 台商大規模撤資或資金外流

### 社會民生徵兆
- [ ] 台灣政府發布特殊準備指令
- [ ] 民生物資搶購潮出現
- [ ] 交通運輸系統異常調整
- [ ] 大型國際活動取消或延期

**當你觀察到多個徵兆同時出現，應立即：**
1. 聯絡台灣家人，確認安全
2. 檢查緊急準備是否完整
3. 關注官方與可信媒體消息
4. 準備必要時提供緊急支援
