# 協助急難的家人與朋友

當緊急狀況發生時，你最優先的任務是確保最親近的人安全。這是你的第一道責任。

## :one: 第一時間聯絡（0-30分鐘）

### 聯絡順序優先級
1. **配偶與子女**
2. **父母與兄弟姊妹**
3. **祖父母與至親**
4. **最親近的朋友**
5. **其他親戚**

### 通訊方式檢查清單
- [ ] **手機通話**：直接撥打，多試幾次
- [ ] **LINE**：發送訊息與語音通話
- [ ] **WhatsApp**：國際通訊較穩定
- [ ] **Facebook Messenger**：可能在其他方式失效時仍可用
- [ ] **Email**：發送緊急郵件
- [ ] **透過第三人聯絡**：請其他親友代為聯絡

### 緊急聯絡資訊確認
對每個重要家人，你需要有：
- [ ] 至少3種聯絡方式（手機、市話、社群軟體）
- [ ] 工作地點與聯絡資訊
- [ ] 鄰居或朋友的聯絡方式
- [ ] 緊急狀況下的預定會合地點

## :two: 安全狀況評估（30分鐘-2小時）

### 重要確認事項
**對每個聯絡上的家人，詢問：**

**基本安全**：
- [ ] 人身是否安全？有無受傷？
- [ ] 目前在哪裡？是否安全？
- [ ] 房屋是否受損？是否需要撤離？
- [ ] 有沒有足夠的食物和飲水？

**通訊狀況**：
- [ ] 手機與網路是否正常？
- [ ] 電力供應是否正常？
- [ ] 其他家人的聯絡狀況？
- [ ] 政府是否有發布特別指示？

**immediate needs**：
- [ ] 是否需要醫療協助？
- [ ] 是否需要緊急資金？
- [ ] 是否需要協助撤離？
- [ ] 是否需要特殊物資？

## :three: 立即支援行動（2-6小時）

### 資金支援
**緊急匯款管道**：
- [ ] **銀行國際匯款**：最安全但可能較慢
- [ ] **Western Union**：快速，全球據點多
- [ ] **MoneyGram**：替代方案
- [ ] **行動支付**：如果服務正常（LINE Pay、街口支付）
- [ ] **請朋友代墊**：緊急時請台灣的朋友先墊付

**匯款金額建議**：
- 輕微緊急：$500-$1,000 美金
- 中度緊急：$1,000-$3,000 美金  
- 嚴重緊急：$3,000+ 美金

### 物資支援
**網路採購**（如果網路商城仍運作）：
- [ ] **食物**：非即食罐頭、餅乾、泡麵
- [ ] **飲水**：瓶裝水、淨水設備
- [ ] **醫療用品**：急救包、常用藥品
- [ ] **通訊設備**：充電寶、電池、收音機

**聯絡台灣朋友代購**：
- [ ] 請台灣朋友協助採購
- [ ] 你負責線上付款或事後償還
- [ ] 優先購買：食物 > 藥品 > 通訊設備

### 醫療協助
**如有家人受傷或需要醫療協助**：
- [ ] 協助聯絡當地醫院
- [ ] 提供醫療費用支援
- [ ] 聯絡台灣友人陪同就醫
- [ ] 保持與醫療人員的聯絡

## :four: 持續支援計畫（6-24小時）

### 建立定期聯絡機制
- [ ] **約定聯絡時間**：每6-12小時報平安
- [ ] **建立備用聯絡人**：如果直接聯絡中斷
- [ ] **紀錄重要資訊**：每次通話的重點與需求
- [ ] **更新其他家人**：讓所有人知道最新狀況

### 長期需求評估
**評估可能的長期需要**：
- [ ] **住宿安排**：如果家被毀需要暫時住處
- [ ] **生活費支援**：如果工作中斷需要生活費
- [ ] **醫療支援**：如果有持續的醫療需求
- [ ] **心理支援**：提供情感上的支持與鼓勵

### 撤離支援（如需要）
**如果家人需要撤離台灣**：
- [ ] **確認護照有效性**：協助更新或補發護照
- [ ] **申請美國簽證**：如果需要來美國
- [ ] **購買機票**：儘快預訂可用航班
- [ ] **準備接機住宿**：在美國的住宿安排
- [ ] **聯絡移民律師**：了解法律程序與選項

## :heart: 心理支持指南

### 給家人的情感支援
- **保持冷靜**：你的冷靜會傳遞安定感
- **積極傾聽**：讓家人表達恐懼與擔心
- **給予希望**：提醒他們你會持續支援
- **實際行動**：用具體行動表達關愛

### 照顧自己
- **不要獨自承擔**：尋求朋友與社區支援
- **維持基本需求**：確保自己的睡眠與飲食
- **尋求專業協助**：必要時尋求心理諮商
- **分享壓力**：與其他台美人分享經驗

## :muscle: 記住

你的家人知道你在美國關心他們、支援他們，這本身就是巨大的力量來源。距離不能阻隔愛與支援，你的每一個行動都在為他們的安全與希望貢獻力量。

保持聯絡，提供支援，傳遞愛。這就是身在美國的你能給家人最大的禮物。
