# 建立家人支援計畫

本站不會要求登入，也不會儲存你的聯絡人、文件或家庭計畫。請把以下內容用你與家人都能取得的方式保存，並定期演練。

## 今天先做這三件事

1. **確認兩位聯絡人**：指定一位台灣主要聯絡人與一位備援聯絡人；彼此確認電話、通訊軟體與 email。
2. **約定報平安方式**：約定固定時間、簡短的平安訊息，以及超過多久未回覆時由誰聯絡誰。
3. **找到重要資訊**：確認家人知道護照、身分證件、常用藥、醫療資訊與緊急聯絡卡放在哪裡。

## 建立一張家庭聯絡卡

請和家人一起填寫並離線保存：

- 主要聯絡人與備援聯絡人的姓名、電話、email
- 固定報平安時間與未回覆時的下一步
- 緊急會合地點與替代地點
- 慢性病、過敏、固定用藥與照顧需求
- 證件與重要文件的保存位置
- 在台灣與海外可用的資金支援方式

## 訊息中斷時

先依照家人所在縣市與官方公告行動。不要只依賴單一通訊軟體；事前下載並熟悉多種通訊方式，也把重要電話寫在紙本聯絡卡上。

台灣家人可使用官方防災工具查詢避難收容處所、救濟站、物資配售站與防空避難所；海外親友的角色是協助確認資訊、維持聯絡，不是替代現場官方指示。
