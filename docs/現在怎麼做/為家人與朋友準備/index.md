# 為家人與朋友準備

幫助在台灣的家人朋友做好緊急準備，是身在美國的我們最重要的責任。

## :iphone: 緊急通訊準備

### 建立多元通訊管道
- [ ] **教家人下載多種通訊軟體**：LINE、WhatsApp、Signal、Telegram
- [ ] **建立家族群組**：確保每個重要成員都在群組內
- [ ] **準備衛星通訊**：考慮 Starlink 等衛星網路服務
- [ ] **約定聯絡頻率**：建立定期報平安的時間表

### 斷網情況通訊準備
- [ ] **下載離線通訊軟體**：
    - Briar（點對點加密通訊）
    - Bridgefy（藍牙網狀網路）
    - FireChat（附近的人通訊）
- [ ] **教會使用方法**：提前教導家人如何使用這些軟體
- [ ] **建立社區網絡**：與鄰居、社區建立互助通訊群組

## :package: 物資準備支援

### 緊急避難包清單
**幫家人準備或提醒準備**：

**基本生存物資**：
- [ ] 3天份的飲用水（每人每天4公升）
- [ ] 3天份的不需烹煮食物（罐頭、餅乾、營養棒）
- [ ] 手電筒與電池
- [ ] 收音機（手搖或電池式）
- [ ] 急救箱與常用藥物

**重要文件**：
- [ ] 身分證、護照影本（防水袋包裝）
- [ ] 保險單影本
- [ ] 重要財產證明
- [ ] 緊急聯絡人清單
- [ ] 個人醫療資訊卡（血型、過敏、慢性病）

**其他必需品**：
- [ ] 現金（小面額）
- [ ] 充電寶與充電線
- [ ] 保暖衣物與雨具
- [ ] 個人衛生用品
- [ ] 瑞士刀或多功能工具

### 網購支援策略
**從美國幫台灣家人網購物資**：

- [ ] **事先設定帳號**：在蝦皮、momo、PChome 設定好購物車
- [ ] **約定下單時間**：與家人協調驗證碼接收時間
- [ ] **優先物資清單**：食物 > 藥品 > 電池 > 急救用品
- [ ] **分散風險**：不要全部依賴單一平台

## :round_pushpin: 避難計畫制定

### 避難地點規劃
- [ ] **協助查找避難所**：使用[內政部警政署防空疏散避難專區](https://adr.npa.gov.tw/)
- [ ] **制定撤離路線**：至少準備2條不同路線
- [ ] **確定會合地點**：約定家人走散時的會合地點
- [ ] **備案地點**：親戚朋友家或其他可投靠地點

### 重要文件下載
- [ ] **全民國防應變手冊**：[下載連結](https://adma.mnd.gov.tw/files/web/191/file_up/100004/60/%E5%85%A8%E6%B0%91%E5%9C%8B%E9%98%B2%E6%87%89%E8%AE%8A%E6%89%8B%E5%86%8A.pdf)
- [ ] **消防防災 e 點通 App**：[iOS](https://apps.apple.com/us/app/消防防災e點通/id1500403641) | [Android](https://play.google.com/store/apps/details?id=com.nfa.report)
- [ ] **台灣全民安全指引**：[prepare.mnd.gov.tw](https://prepare.mnd.gov.tw/)

## :hospital: 醫療準備

### 藥物儲備
- [ ] **常用藥物**：慢性病用藥至少儲備1個月份
- [ ] **急救藥物**：止痛藥、腸胃藥、感冒藥
- [ ] **特殊需求**：嬰兒用品、老人用品
- [ ] **醫療器材**：血壓計、血糖機（如有需要）

### 醫療資訊準備
- [ ] **個人醫療卡**：血型、過敏史、慢性病、緊急聯絡人
- [ ] **醫院聯絡資訊**：常就診醫院的聯絡方式
- [ ] **保險資訊**：健保卡、商業保險單號

## :moneybag: 財務準備

### 緊急資金
- [ ] **現金準備**：建議準備1-3個月的生活費現金
- [ ] **多幣種準備**：台幣、美金、黃金
- [ ] **銀行資訊**：多家銀行帳戶資訊與密碼
- [ ] **海外匯款**：確保能夠快速從美國匯款到台灣

### 重要財產
- [ ] **房地產證明**：權狀影本、租約
- [ ] **保險單據**：人壽保險、財產保險
- [ ] **投資證明**：股票、基金、債券證明
