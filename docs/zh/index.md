# 現在就和家人約好：遇到緊急狀況時，怎麼聯絡、怎麼報平安。

<p class="lede">趁平常先約好怎麼聯絡、重要資料放在哪裡，以及彼此能做什麼。這裡不會預測危機或蒐集你的資料；需要判斷現場情況時，請以家人所在地和台灣官方公告為準。</p>
